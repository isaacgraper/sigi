# Vendored skills

Thirteen skills in this directory are copied from Emil Kowalski's public skill
collection. The other two, `sigi-domain` and `spec-format`, belong to this
repository.

Copied unchanged: `animate`, `animate-expo`, `animation-vocabulary`,
`apple-design`, `ask-sonner`, `emil-design-eng`,
`find-animation-opportunities`, `improve-animations`, `mobile-native`,
`pick-ui-library`, `prototype`, `review-animations`, `write-swift`.

`write-swift` and `animate-expo` target native iOS and React Native. They are
here so the collection stays whole, but mobile apps are out of scope for SIGI
(CLAUDE.md), so no work on this repository should invoke them.

## Updating

Do not edit these files in place. A local change turns every future update into
a merge. To update, clone the source again, copy each `skills/<name>/` directory
over the copy here, and change the commit hash above in the same commit. Anything
SIGI needs to add or override belongs in `sigi-domain` or in a new skill of our
own.
