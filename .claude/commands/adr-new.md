description: Record an architecture decision
argument-hint: <decision in one line>
allowed-tools: Read, Write, Glob
---

Record this decision: $ARGUMENTS

1. Read `docs/architecture/adr/ADR-TEMPLATE.md` and the existing ADRs; check
   whether this supersedes one.
2. Take the next number.
3. Write the ADR. The context section must state the forces and constraints, not
   just restate the decision.
4. **Options considered must include at least one real alternative** with genuine
   pros. An ADR that presents a single option is a press release.
5. The consequences section must include honest negatives and the follow-up work
   the decision creates elsewhere.
6. Update the index table in `docs/architecture/adr/README.md`.
7. If the decision contradicts `CLAUDE.md` or an existing spec, say so
   explicitly and list what must change.
